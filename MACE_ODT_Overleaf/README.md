# MACE-ODT Overleaf package

This folder is ready to upload to Overleaf as a project.

Files:

- `main.tex` is the complete research direction paper.
- `mace_neurips.sty` provides a compact two-column, NeurIPS-inspired layout without conference branding.
- `references.bib` contains the four references used in the note.
- `MACE_ODT_Research_Direction.pdf` is the compiled preview.

Compile with pdfLaTeX and BibTeX. On Overleaf, the default `latexmk` build should work without changes.

The paper intentionally separates verified mathematics, source-reported results, feasibility judgments, and proposed work. It does not claim that a real MACE checkpoint has already been compressed or decomposed.
